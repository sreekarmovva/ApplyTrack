# ApplyTrack

ApplyTrack is a job application tracker built with Python, FastAPI, PostgreSQL, HTML, CSS, and JavaScript.

## Goal

Build a full-stack application to record job applications, track recruitment stages, and manage job-search progress.

Project setup in progress.
